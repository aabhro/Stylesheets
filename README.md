# Stylesheets

A collection of reusable interface design guides and stylesheets for AI-assisted and hands-on web development.

## Repository structure

```text
Stylesheets/
├── README.md
└── Styles/
    └── Modernimal Stylesheet.md
```

## Styles

- [Modernimal Stylesheet](Styles/Modernimal%20Stylesheet.md)  
  A general-purpose UI design guide for minimal, monochrome interfaces. It covers visual hierarchy, list-first layouts, custom controls, context menus, accessibility, responsiveness, performance, and implementation workflow.

## How to use a style

1. Open the stylesheet relevant to your project.
2. Share it with your AI coding assistant or use it as your own design reference.
3. Treat it as a baseline. The current project requirements and explicit instructions take priority.
4. Preserve existing features and architecture unless a change is requested.

## Adding styles

- Keep stylesheet documents inside `Styles/`.
- Use clear, descriptive filenames.
- Keep each guide self-contained and focused on a distinct design direction or use case.
- Add new styles to the list above so they are easy to discover.

## Guiding principles

Styles in this repository should be practical, reusable, and easy to apply. Prefer clear instructions, consistent terminology, accessible interactions, and concrete implementation guidance over vague aesthetic descriptions.
